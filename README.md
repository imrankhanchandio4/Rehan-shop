# Rehan Computer Shop - Website

Modern, fully responsive website for **Rehan Computer Shop**.

## Features

- Home, Products, Services, About & Contact pages
- Mobile-friendly responsive design
- Product category filter (Laptops, Desktops, Accessories, Components)
- Contact form with success message
- WhatsApp floating button
- Clean modern UI with blue theme

## How to Use

1. Extract the ZIP file
2. Open `index.html` in any browser
3. No installation or server needed (static website)

## Customize

- **Phone number**: Search and replace `+92 300 1234567`
- **Address / Email**: Edit in all HTML files (footer + contact page)
- **Products / Prices**: Edit `products.html`
- **Colors**: Edit CSS variables in `css/style.css` (`:root`)

## Notes

- Font Awesome icons are loaded from CDN (internet required for icons)
- Contact form is frontend-only (shows success message, does not send email)
- You can later connect the form to WhatsApp, EmailJS, or a backend
